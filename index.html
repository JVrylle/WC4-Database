Everything about this application

This database is built for the World Conqueror community: free access and easy search across generals, elite forces and skills — ranks, stars, per-level stats with max technology, upgrade costs and full skill effects.

Use the search bars to find anything by name, filter by tier or unit type, and drag the level sliders to inspect every stage of progression. Pick a system below to start searching.

How to use

1. Search — type a few letters; results filter instantly. 2. Filter — pills narrow by tier or unit type and auto-load the first match. 3. Inspect — move level sliders to compare stats, costs and skills at every stage. Hover any skill medal or chip for its full effect text.
